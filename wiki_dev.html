9. Dev Warnings & Data Issues

1. CMD audit: Known collisions were fixed. Current new IDs: Chronos 2006, Cursed Player Head 4004, Warden Resonance 4005, Plundered Heart 4006, Vile Ledger 4007, Avarice Ritual Core 3012, Soul Sever 5004, Avarice Blade 5005.
2. Chronos Anchor Spear — cơ chế lệch rule: Dùng SpearProjectileService (throw) thay vì AbilityService (Sneak+LeftClick). Rule hiện tại: "Active input = Sneak + Left Click only". Cần quyết định: chuyển sang AbilityService hoặc cập nhật rule cho spear.
3. Ritual Crafting Table: T39 added delayed transform, timed craft locking, and table cooldown. Live-server anti-dupe tests are still recommended for reload/disconnect mid-craft.
4. Vampiric Spear — legacy id: File YAML là vampiric_mace.yml, id PDC là vampiric_mace, nhưng display name là "VAMPIRIC SPEAR", material là NETHERITE_SPEAR, weapon-class SPEAR. Ability class vẫn tên VampiricMaceAbility. Follow-up T30: rename class/id sâu hơn (optional).
5. Warden Blade replaced: warden_blade source resource and generated output are removed. soul_sever_spear is the replacement weapon.
6. Vile Ledger first slice: Current drop hook uses Evoker death + nearby Ravager fallback. Full max-level final-wave raid boss encounter remains a future refinement.
