0. Rules

  • Build command: cmd /c "gradle build --no-daemon", timeout 120000ms.
  • Core must be center slot in every special weapon/core recipe.
  • All ancient weapons need Active + Passive + Curse.
  • Glowing is universal curse, not per-weapon copy.
  • Ritual-derived cores use display name: Blood/Sculk/Echo/Void/Reaper Ritual Core.
