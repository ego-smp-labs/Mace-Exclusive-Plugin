2. Hard gameplay rules

  • Active input = Sneak + Left Click only.
  • Mỗi vũ khí cổ truyền phải có đủ Active, Passive, Curse.
  • Glowing là lời nguyền chung khi cầm mọi vũ khí cổ truyền; không ghi lặp lại thành curse riêng từng món.
  • Core phải nằm ở ô giữa 3x3 trong mọi recipe weapon/core.
  • Core sinh từ Ritual Core phải có chữ Ritual Core trong display name: Blood/Sculk/Echo/Void/Reaper Ritual Core.
  • Void Ritual Core fail qua End Portal = mất Ritual Core + Challenger's Eye vĩnh viễn, không trả Ruined Core.
  • Ritual Core không rơi từ Pillager/Evoker. Evoker-related items dùng cho sword/exclusive weapon recipes, không phải nguồn Ritual Core.
