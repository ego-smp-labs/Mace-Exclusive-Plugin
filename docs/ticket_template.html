Priority Tags

  • P0 — Fix bug khẩn cấp (crash, mất đồ, không hoạt động).
  • P1 — Feature core (thay đổi hành vi chính, kiến trúc mới).
  • P2 — Feature mở rộng (thêm vũ khí, UI).
  • P3 — Polish (balance, docs, cleanup).

Status Tags

  • Idea — Ý tưởng, chưa lên kế hoạch chi tiết.
  • Planned — Đã có ticket chi tiết, sẵn sàng cho backend.
  • In Progress — Backend đang làm.
  • Done — Hoàn thành, build pass, đã report.

Quy tắc

  • 1 ticket = 1 PR/commit. Không gộp nhiều ticket.
  • Build pass (timeout 120s) trước khi báo Done.
  • Core luôn ở chính giữa (slot 4) trong mọi recipe.
  • UTF-8. Adventure API. PDC identity.
  • Check offhand slot trong mọi inventory validation.
  • Không paste full plan vào chat. Ghi docs trước.
